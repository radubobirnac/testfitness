Brave Search MCP Server Demo

This demo shows how to use the Brave Search MCP server for web and local search capabilities.

What is Brave Search?

The Brave Search MCP server provides tools for accessing the Brave Search API, allowing for:

  • General web searches for information, news, and articles
  • Local searches for businesses, restaurants, and services
  • Filtering and pagination controls
  • Automatic fallback from local to web search when needed

How to Use Brave Web Search

The Brave Web Search tool accepts the following parameters:


{
  "query": "your search query",
  "count": 10, // Optional: Number of results (max 20)
  "offset": 0  // Optional: Pagination offset (max 9)
}

Example Web Search Query:

Search for: "artificial intelligence latest developments"

Parameters:


{
  "query": "artificial intelligence latest developments",
  "count": 5
}

How to Use Brave Local Search

The Brave Local Search tool accepts the following parameters:


{
  "query": "your local search query (e.g., 'coffee shops near central park')",
  "count": 5  // Optional: Number of results (max 20)
}

Example Local Search Query:

Search for: "pizza restaurants in Boston"

Parameters:


{
  "query": "pizza restaurants in Boston",
  "count": 3
}

Advanced Features

  • Pagination: Use the offset parameter for web searches to navigate through results
  • Result Filtering: The server automatically handles content filtering based on Brave API settings
  • Automatic Fallback: Local searches with no results will fall back to web search
  • Detailed Information: Local search results include ratings, hours, phone numbers, and more
