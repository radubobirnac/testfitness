Sequential Thinking MCP Server Demo

This demo shows how to use the Sequential Thinking MCP server for structured problem-solving and dynamic thought processes.

What is Sequential Thinking?

The Sequential Thinking MCP server provides tools for breaking down complex problems into manageable steps, allowing for:

  • Step-by-step breakdown of complex problems
  • Revising and refining thoughts as understanding deepens
  • Branching into alternative paths of reasoning
  • Adjusting the total number of thoughts dynamically
  • Generating and verifying solution hypotheses

How to Use the Sequential Thinking Tool

The Sequential Thinking tool accepts the following parameters:


{
  "thought": "Your current thinking step",
  "nextThoughtNeeded": true/false,
  "thoughtNumber": 1, // Current thought number
  "totalThoughts": 5, // Estimated total thoughts needed
  "isRevision": false, // Whether this revises previous thinking
  "revisesThought": 0, // Which thought is being reconsidered
  "branchFromThought": 0, // Branching point thought number
  "branchId": "", // Branch identifier
  "needsMoreThoughts": false // If more thoughts are needed
}

Example Problem: Fitness App Workout Planning

Here's an example of using sequential thinking to design a workout plan for a fitness app user:

Problem:

Design a personalized 4-week workout plan for a beginner who wants to improve general fitness and has access to a gym 3 days per week.

Sequential Thinking Process:

Thought 1: First, I need to understand what "general fitness" encompasses and what components should be included in a balanced workout plan. Generally, this would include cardiovascular endurance, muscular strength, muscular endurance, flexibility, and body composition improvements.

Thought 2: For a beginner with 3 days per week availability, we should create a full-body approach rather than a body-part split. This maximizes efficiency and ensures each muscle group gets adequate training frequency (about 2-3 times per week).

Thought 3: Actually, I should revise my previous thought. While a full-body approach is good, for a 4-week plan, we might consider a progression: Weeks 1-2 with full-body workouts to build foundation, then Weeks 3-4 with an upper/lower split to introduce more targeted volume as adaptation occurs.

Thought 4: Each workout should include:
- A 5-10 minute warm-up (light cardio + dynamic stretching)
- 20-30 minutes of resistance training (8-10 exercises, 2-3 sets, 10-15 reps)
- 10-15 minutes of cardiovascular exercise (moderate intensity)
- 5 minute cool-down (static stretching)

Thought 5: We should also consider progression principles. Week 1 should focus on form and technique with lighter weights. Each subsequent week should introduce either:
- Increased weight (5-10% increase when possible)
- Increased repetitions (1-2 more reps per set)
- Increased sets (add one set to key exercises)
- Decreased rest periods (from 90 seconds to 60 seconds between sets)

Thought 6: I initially estimated 5 thoughts, but I need to add more thoughts to fully address this problem. Let's consider specific exercises to include in the plan.

Thought 7: For a beginner-friendly resistance training, focus on fundamental movement patterns:
- Push: Push-ups, bench press, shoulder press
- Pull: Assisted pull-ups, rows
- Squat: Bodyweight squats, goblet squats, leg press
- Hinge: Romanian deadlifts, hip thrusts
- Core: Planks, bird-dogs, dead bugs

Thought 8: Final solution: A progressive 4-week plan with 3 workouts per week. Beginning with full-body sessions focusing on technique, gradually increasing intensity and evolving to an upper/lower split in the final weeks. Each session includes warm-up, resistance training covering all movement patterns, cardiovascular work, and cool-down stretching.
